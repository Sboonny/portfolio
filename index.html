About

Open-source engineering, reviewed in public

I started contributing to freeCodeCamp as a volunteer in spring 2022 and was hired full-time that July. For the next 16 months I worked across the React/TypeScript client, the new Node.js API and Chapter, freeCodeCamp's event-management tool for nonprofits.

Most of my work is on the frontend: CSS architecture, shared components and layouts that work in both writing directions. As a native Arabic speaker, I built the platform's right-to-left support. I'm just as comfortable on the server, writing Fastify routes with Prisma or GraphQL features with Apollo and PostgreSQL.

Every change I've made there went through public code review. You can read all 560 merged pull requests on GitHub.

freeCodeCamp · 2022–2023

Right-to-left layout for freeCodeCamp.org

Problem
The float-based React client had no right-to-left support, so Arabic learners got a left-to-right interface.
Solution
RTL layout support: mirrored navigation, RTL typography, direction-aware icons and a root dir attribute. Spacing moved to CSS logical properties so components work in both directions.
My contribution
Authored the initial RTL PR, then about 20 follow-ups covering the code console, profile, search, challenge tables and code blocks.
  • React
  • TypeScript
  • CSS logical properties
  • Flexbox / Grid
  • i18n
